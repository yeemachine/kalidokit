# 个人二维画像：第一版

从仓库根目录启动：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

访问 http://localhost:8000/puppet/ 。

## 已实现

- 根据用户提供的参考照片，预先制作一份个人卡通形象。
- 独立眼部贴片与闭眼线条；保留原画的眼镜和眉毛。
- 上下唇贴片、简化口腔和牙齿；连续控制张嘴幅度。
- 手动滑块、明确标记的自动演示，以及摄像头驱动。
- 中性状态校准、参数平滑、单人脸丢失时回到中性表情、关闭摄像头。
- 下载当前合成画面。

## 素材与制作说明

画像使用内置图像生成工具制作，不依赖额外 API key。实际使用的提示词约束如下：

1. 使用截图左侧真人画面作为身份参考，忽略右侧图像处理结果与界面。绘制同一个人的正面卡通头肩像，保留脸型、蓬松黑色卷发、深色细框眼镜、格纹衬衣；自然睁眼、闭嘴，简化中央面部阴影，浅蓝灰背景，无文字。
2. 在主画像上仅去除双眼及嘴唇，并补画匹配的皮肤，保留位置、眼镜、眉毛、鼻子及其他内容，形成干净底图。

`portrait.webp` 是主画像；`clean.webp` 是补画底图。两者由生成结果转换为 1024×1024 WebP。运行时预烘焙眼睛和嘴唇贴片，再以 Canvas 2D 合成。

## 运行方式与限制

手动模式和演示模式仅依赖同目录静态资源。摄像头模式首次加载固定版本 MediaPipe FaceMesh 0.4.1633559619 的脚本、模型与 WASM；图像和表情处理在本浏览器执行，没有发送图像到图像生成服务的逻辑。

当前人物素材已预先生成，不是一个能给任意新用户自动生成形象的完整产品。眼睛使用原画贴片压缩与裁剪，嘴部使用简化的唇片位移，暂时不包含精确发音嘴型、眼球视线驱动或侧脸。倾斜作用于整幅头肩画像，尚未把头部与身体独立绑定。

人工检查了中性、闭眼、张嘴、单眼闭合、半开与倾斜六种 Canvas 渲染状态；检查了中性/闭眼/张嘴参数映射和 JavaScript 语法。真实浏览器摄像头端到端验证需要在用户电脑上进行。
